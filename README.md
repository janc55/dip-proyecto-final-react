# TaskMaster - Gestión de Tareas con React

![TaskMaster Preview](https://via.placeholder.com/800x400/0f172a/6366f1?text=TaskMaster+React+App)

**TaskMaster** es una aplicación de gestión de tareas (To-Do List) moderna y sofisticada, desarrollada con **React** y **Vite**. Este proyecto forma parte del módulo de "Frontend Development" del Diplomado Full Stack.

## 🚀 Características

- **Diseño Premium**: Interfaz moderna basada en *glassmorphism*, degradados vibrantes y micro-animaciones fluidas.
- **Autenticación Completa**: Registro de usuarios e inicio de sesión con JWT persistente en `localStorage`.
- **Gestión CRUD de Tareas**:
  - Listado dinámico desde API remota.
  - Creación de nuevas tareas.
  - Edición de nombres de tareas existentes.
  - Alternancia de estado (Pendiente / Finalizada) con estilos visuales diferenciados.
  - Eliminación de tareas con confirmación.
- **UX Optimizada**: Estados de carga (loaders), manejo de errores amigable y diseño responsive.

## 🛠️ Tecnologías Usadas

- **Core**: [React 19](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **HTTP Client**: [Axios](https://axios-http.com/)
- **Iconos**: [Lucide React](https://lucide.dev/)
- **Estilos**: Vanilla CSS con variables modernas y Flexbox/Grid.
- **Despliegue**: GitHub Pages.

## 📦 Instalación y Uso Local

1.  **Clonar el repositorio**:
    ```bash
    git clone https://github.com/TU_USUARIO/proyecto-final-react.git
    cd proyecto-final-react
    ```

2.  **Instalar dependencias**:
    ```bash
    npm install
    ```

3.  **Correr el servidor de desarrollo**:
    ```bash
    npm run dev
    ```
    La aplicación estará disponible en `http://localhost:5173`.
